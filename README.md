# CRMP Bot

Telegram-бот для проекта CRMP: проекты, моды, поддержка, партнёрка.

## Возможности

- 🎮 **Проекты** — список проектов со ссылками
- 🛠 **Моды** — моды и сборки со ссылками
- 💬 **Поддержка** — вопросы пользователей приходят админу в личку
- 🤝 **Партнёрка** — условия и контакт менеджера
- 📢 **Канал** — быстрая ссылка на канал

## Файлы

| Файл | Назначение |
|------|-----------|
| `bot.py` | код бота |
| `requirements.txt` | зависимости |
| `Procfile` | команда запуска для хостинга (Railway, Render, Heroku) |
| `.gitignore` | что не загружать в репозиторий |

## Настройка

Все тексты и ссылки находятся вверху `bot.py`, в блоке `НАСТРОЙКИ`:
`PROJECT_NAME`, `CHANNEL_LINK`, `PARTNER_CONTACT`, `PROJECTS`, `MODS`, `PARTNER_TEXT`.

## Переменные окружения

| Переменная | Что это |
|-----------|---------|
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | Telegram ID админа, куда приходят обращения |

Токен никогда не пишите в код и не загружайте в репозиторий.

## Запуск локально

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен"
export ADMIN_ID="ваш_id"
python bot.py
```

## Деплой

1. Загрузите файлы в репозиторий GitHub.
2. Подключите репозиторий на Railway / Render / Heroku как **worker**.
3. Добавьте переменные `BOT_TOKEN` и `ADMIN_ID` в настройках хостинга.
4. Запустите деплой и отправьте боту `/start`.

Запускайте только одну копию бота с одним токеном, иначе будет ошибка `Conflict`.
